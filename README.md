# Claude's Color Pulse 🎨

> 一款由 Claude 打造的色彩匹配反应力挑战游戏

---

## 游戏玩法

- 屏幕上方显示**目标颜色**
- 下方色块中只有**1个**颜色完全匹配
- 在**倒计时结束前**点击正确色块
- 点击正确 ➕10分，时间重置
- 点击错误 ➖3秒，并有抖动反馈
- 时间耗尽 → 游戏结束

---

## 功能特性

✅ 实时计分 + 本地最高分记录  
✅ 倒计时进度条  
✅ 正确/错误视觉反馈动画  
✅ 游戏结束画面 + 重新开始  
✅ 手机/电脑响应式布局  
✅ 毛玻璃质感设计  
✅ 难度逐渐增加（时间减少）  
✅ 连击提示特效
